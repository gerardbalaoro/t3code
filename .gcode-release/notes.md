#### Lucide project icons on mobile

Mobile displays selected Lucide project icons supplied by the server. Cached icons remain available offline.

- See resource warnings and CPU, memory, and disk use in thread details.
- Control whether T3 Code can read each agent’s usage history and sign-in information.
- Snooze threads until you choose to bring them back.

#### Install G Code alongside T3 Code

G Code ships its own desktop app, `gcode` launcher, and background service. Both apps can use the projects, settings, and history in `~/.t3`. Close one app and stop its service before starting the other.

This is the first regular G Code release. Install it from the [G Code downloads](https://github.com/gerardbalaoro/t3code/releases/latest) to switch from a G Code nightly.
